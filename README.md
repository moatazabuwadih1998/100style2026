# مكتبة أساليب فنون الألعاب والأنمي | Anime & Game Style Studio

> **المنصة العربية المتكاملة لتحويل الشخصيات إلى 100 أسلوب فني في ألعاب الفيديو والأنمي مع باني برومبتات ذكي، استوديو تحكم بالنتائج، وأدوات مقارنة بصرية وتصدير شامل.**

**الإصدار:** 1.0.0  
**الترخيص:** Apache-2.0  
**اللغة الأساسية:** العربية (RTL) مع دعم كامل للإنجليزية في مصطلحات الفن والبرومبتات.

---

## 🌟 نظرة عامة على المشروع (Project Overview)

تم تصميم وبناء هذه المنصة لتكون مرجعاً هندسياً وفنياً متكاملاً للمصممين ومطوري الألعاب ومحترفي توليد الصور بالذكاء الاصطناعي. تضم المنصة **100 أسلوب فني** حقيقي موزع بدقة متناهية على **10 مجموعات تخصصية** (10 أساليب لكل مجموعة)، مع ترقيم فريد من نوعه (`g01-s01` إلى `g10-s10`)، ومعاينات بصرية متجهة، وباني برومبتات تفاعلي، واستوديو توليد صور متصل بـ OpenAI API، ومقارنات بصرية متطورة قبل/بعد.

## 🛠️ البنية التقنية (Architecture)

- **Frontend:** React 19 SPA, TypeScript 5+, Tailwind CSS 4+
- **Icons & Motion:** Lucide React, Motion
- **Backend Server:** Node.js, Express 4, tsx
- **Development Server:** Express + Vite Middlewares on port 3000
- **AI Integration:** OpenAI Images API Proxy (`/api/generate-image`) مع حماية كاملة للمفاتيح السرية ومنع تسريبها للعميل.
- **Export Engine:** JSZip لتوليد الحزم المضغوطة لحظياً.

## 🚀 التثبيت والتشغيل (Installation & Setup)

### 1. تثبيت الاعتماديات:
\`\`\`bash
npm install
\`\`\`

### 2. إعداد مفتاح OpenAI:
انسخ ملف \`.env.example\` إلى \`.env\` وضع مفتاحك:
\`\`\`bash
cp .env.example .env
\`\`\`
محتوى \`.env\`:
\`\`\`env
OPENAI_API_KEY="sk-proj-..."
\`\`\`

### 3. تشغيل خادم التطوير:
\`\`\`bash
npm run dev
\`\`\`
يفتح التطبيق على: \`http://localhost:3000\`

### 4. البناء والتشغيل للإنتاج:
\`\`\`bash
npm run build
npm start
\`\`\`

## 📁 ملفات التصدير المرفقة (Export Files)

- \`100-styles.html\`: صفحة ويب تفاعلية تعمل أوفلاين مع البحث والفلترة.
- \`100-styles.json\`: بيانات الـ 100 أسلوب كاملة بتنسيق JSON.
- \`100-styles-comfyui.csv\`: متوافق مع ComfyUI و SD WebUI Style Loaders.
- \`prompts-library.txt\`: مكتبة نصية بالبرومبتات والسلبيات والكلمات المفتاحية.
- \`notion-styles.csv\` و \`notion-styles.md\`: متوافق مع استيراد Notion و Obsidian.

## 🔒 الأمان وحماية البيانات (Security)

1. **حماية مفتاح API:** يتم حفظ المفتاح كمتغير بيئة في الخادم الخلفي فقط، ولا يتم إرساله للمتصفح تحت أي ظرف.
2. **حدود الاستخدام (Rate Limiting):** تحديد 10 طلبات في الدقيقة كحد أقصى لكل IP و 100 طلب يومياً لتفادي الاستهلاك غير المقصود.
3. **حجم الملفات:** التحقق من صيغ الصور (PNG, JPEG, WebP) وألا يتجاوز الحجم 10 ميغابايت.
4. **التخزين المحلي:** تخزين المفضلة وسجل العمليات محلياً على جهاز المستخدم (LocalStorage) لضمان الخصوصية وسرعة الوصول.
